# Tests Code Style & Conventions

When writing or modifying python code in /test folder, strictly adhere to the following coding standards and guidelines.

## Python rules:

- Keep code small, simple, and readable.
- Prefer standard library; avoid unnecessary dependencies.
- Follow PEP 8 and use clear names.
- Don't over-engineer or add abstractions without need.
- Make the smallest change that solves the task.
- Handle errors explicitly; don't hide exceptions.
- Reuse existing code before creating new code.
- Keep functions focused and reasonably short.
- Add tests for meaningful behavior changes.
- Never modify unrelated code.
