# unit-tests

There is requirement in project that ClineTestApp and ClineTestCore should have atleast 80 % code coverage.
ClineTestAppUnitTests keep test for ClineTestApp and ClineTestCoreUnitTests keep unit tests for ClineTestCore

## Steps

1. Run unit test and check code coverage
2. If unit test are failing please fix existing tests
3. Add new unit tests for new features and functionality to fullify requirement of 80% code coverage.
